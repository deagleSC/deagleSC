## Featured Project

### [Hirevine](https://github.com/deagleSC/hirevine)

**AI does the screening work; people make the decisions.**

<a href="https://github.com/deagleSC/hirevine">
  <img src="https://raw.githubusercontent.com/deagleSC/hirevine/main/docs/screenshots/analytics-campaign.png" alt="Hirevine campaign analytics" width="100%" />
</a>

A hiring manager describes a role in chat and gets an editable pipeline — resume screening, skills quiz, voice AI interview, final list. Candidates get personal feedback, and every AI score quotes its evidence.

- **Evidence-backed scoring** — resume ranking agrees with human labels at Spearman 0.96
- **Audited for fairness** — name-swap bias and prompt-injection evals run on real code paths
- **Voice AI interviews** — questions drawn from each candidate's own resume

[Live](https://hirevine-manager.vercel.app) · [Code](https://github.com/deagleSC/hirevine)
